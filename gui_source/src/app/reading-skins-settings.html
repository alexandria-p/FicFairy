Operates like a site skin on AO3. Will be applied to downloaded HTML files that you open through FicFairy.

How reading skins work

Nothing is written into your files and nothing is asked of AO3: the skin is put in as a work opens, so a new default shows on every work at once.

Write it as an AO3 work skin is written: every rule starts with #workskin, for example #workskin p {{ '{' }} line-height: 1.6; {{ '}' }}.

A work downloaded from FicHub is laid out differently from one downloaded from AO3, so the same skin can look different on it. It never has a work skin of its own.
